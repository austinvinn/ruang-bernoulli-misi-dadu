Navigasi: satu panah, satu tujuan

Brilliant memakai panah kembali eksplisit, bukan mengandalkan tombol back browser.

  • Arena / Papan Data → panah kiri = kembali ke Beranda
  • Beranda → tidak ada panah; logo tidak bisa diklik
  • URL ber-hash #/misi/3 supaya tombol back HP tetap wajar
  • Progres tersimpan otomatis: keluar kapan pun tidak menghapus data

Progres: tanpa login

Tidak ada akun, tidak ada email-OTP. Progres = localStorage per perangkat.

  • Setiap misi punya status: terkunci / tersedia / berjalan / selesai
  • Misi berikutnya terbuka setelah misi sebelumnya selesai
  • Pindah HP: tombol Pulihkan dari kode / berkas JSON kecil (± 2 KB)
  • Email hanya dipakai sebagai label di laporan, bukan autentikasi

Mulai ulang: dua langkah, bukan alert()

Reset hanya muncul di Beranda, dan hanya kalau sudah ada progres.
